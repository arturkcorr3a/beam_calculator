# Security policy

beam_calculator is a desktop program that does not use the network, so its
security risk is low. Still, if you find a vulnerability (for example, a crafted
project file that runs code when opened), please report it privately.

## Supported versions

Only the most recent release receives fixes.

## Reporting a vulnerability

Use the repository's **Security → Report a vulnerability** tab, which opens a
private report visible only to the maintainer. **Do not open a public issue**
for a vulnerability.

I aim to respond within 14 days; this is a personal project.

## Calculation errors

Wrong design results are not security vulnerabilities in the software sense.
Report them as a normal issue, following [CONTRIBUTING.md](CONTRIBUTING.md).

Remember that beam_calculator does not replace the checking of a responsible,
licensed engineer (see the disclaimer in the [README](README.md)).
